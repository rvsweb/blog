## SDK

* AWS SDK (Software Development Kit)

* Conjunto de herramientas y bibliotecas que facilitan el desarrollo de aplicaciones que interactúan con los servicios de AWS.

### AWS Command Line Interface (CLI)

* Bibliotecas boto3 para SDK de python que permite instanciar clientes de servicios de AWS y realizar operaciones en ellos utilizando scripts de Python.
